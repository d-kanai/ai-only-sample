## React Compiler の lint を Biome の nursery/useReactCompiler で入れた（Issue #451）
- 理由: frontend は手書きの memo を禁じて Compiler に任せている。Compiler が最適化を諦める書き方（render 中の props・ref.current の書き換えなど）は、ビルドもテストも通ったままメモ化されないので、lint で止める。
- 根拠: Biome 2.5.13 で実測（worker と reviewer）。このルールは、いちばん近い package.json が React 19 以上を宣言しているときだけ動く（React 18 か、package.json が無ければ 0 件）。hook が引数を書き換える書き方は検出しない。条件の中の hook の呼び出しは useHookAtTopLevel と両方出る。babel-plugin-react-compiler 1.0.0 の既定は `panicThreshold: "none"`。今の frontend は指摘 0 件。fault injection: ルールを off にすると must-reject が落ち、全体に広げると「外では 0」が落ちる。
- 判断: daiki の決定カード（Biome か ESLint か）の答えを待たず、おすすめの Biome で進めた。nursery は採らない方針の例外にし、条件を lint.md と ADR `quality/20261004-react-compiler-lint-with-biome.md` に書いた。
- 機械化: 縛れる（biome.json の frontend の override と、rule-tests/lint.feature の Scenario）。
